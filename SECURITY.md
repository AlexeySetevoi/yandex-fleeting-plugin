# Security policy

Please report vulnerabilities privately via
[GitHub private vulnerability reporting](https://github.com/AlexeySetevoi/yandex-fleeting-plugin/security/advisories/new),
not in public issues. Only the latest release is supported.

Сообщайте об уязвимостях приватно по ссылке выше, а не в публичных issues. Поддерживается только последний релиз.

Release files carry GitHub artifact attestations (build provenance and SBOM); see «Проверка подлинности» in the README
for how to verify them.
